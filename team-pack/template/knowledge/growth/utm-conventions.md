# UTM conventions

Example starter file. Replace with the team's real rules.

| Parameter | Rule | Example |
|---|---|---|
| `utm_source` | Platform | `youtube`, `meta`, `x`, `discord`, `email` |
| `utm_medium` | Placement type | `video`, `short`, `paid`, `bio`, `newsletter` |
| `utm_campaign` | Campaign slug from the content plan | `2026-11-webinar` |
| `utm_content` | Asset slug, matches the video or ad file name | `ifvg-explainer-v1` |

Rules:
- Lowercase, hyphens, no spaces.
- `utm_content` must match the asset name in the content plan so results can be joined back to the asset.
- Results go to the original task on the board and a monthly summary in this folder.
