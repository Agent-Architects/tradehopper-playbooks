# Grok Bot: Custom Rules (approval rules)

Add under Settings > General > Bot > Custom Rules. Custom Rules apply while Auto Review is on (the default). Each rule can be up to 1,000 characters; the limit is 20 Ask first and 20 Allow automatically rules. If both kinds match, Ask first wins.

## Ask first

1. Any action that spends money, makes a purchase, starts a subscription or uses a saved card.
2. Any change to ad campaigns, budgets, bids or targeting on any ad platform.
3. Publishing, posting, replying or sending a message on any public channel, social platform, email or customer-facing chat.
4. Any action in Stripe, a broker, a prop-firm account or a trading platform.
5. Deleting, archiving or overwriting files, pages, rows, repos or branches.
6. Pushing to the main branch of any GitHub repo, merging a pull request, or changing repo settings or access.
7. Sharing files or granting access to anyone.

## Allow automatically

1. Reading the team GitHub repo, the task board, Notion pages and Google Drive files in the team folders.
2. Commenting on and changing the status of board tasks assigned to me.
3. Creating a branch and opening a pull request in the team brain repo.
4. Searching the web and public X posts.
